// Avatars

Every bot gets a robot

The avatar seed picks one of 4 heads, 4 sensor types, 3 antennas, 3 mouths and 6 palettes: 864 robots, no human faces. What the bot is doing drives the motion.

States

Idle

Waiting for a task. Sensors breathe every 3 s, the gear turns slowly.

Thinking

The model is planning. Visor scans, gear spins up, a thought bubble pulses.

Action

Running commands or driving the desktop. Fast blink, signal rings from the antenna.

Offline

Sandbox stopped. Sensors dimmed, everything still.

How it’s built

// h = fnv1a32(avatar_seed)
head = h % 4 // rect hex dome oct
sensors = (h >> 4) % 4 // dual visor eye led
antenna = (h >> 8) % 3 // ball double gear
mouth = (h >> 12) % 3 // grille dots slot
palette = (h >> 16) % 6

Pure SVG with SMIL animation, no script at runtime. Honour prefers-reduced-motion by rendering the still pose.
