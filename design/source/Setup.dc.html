What happens on completion

  • ✓ Setup secret digest is cleared immediately and /api/setup/* permanently returns 404.
  • ✓ Owner password is hashed with Argon2id; EdDSA JWT (15 min) + HttpOnly refresh cookie are issued.
  • ✓ Every bot, secret and chat is isolated per workspace_id.
  • ✓ Additional teammates join exclusively via signed single-use invitation links.
  • ✓ Initialization event written to audit_log (setup.completed).
