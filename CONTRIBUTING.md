# Contributing to bot.Box

Read the [development rules](AGENTS.md) and follow the
[Code of Conduct](CODE_OF_CONDUCT.md) in project spaces.

Add an `SPDX-License-Identifier: AGPL-3.0-only` comment to new project files
that support comments. If the format cannot hold a comment or the generator
does not carry the comment into its output, record the license in
[REUSE.toml](REUSE.toml). Preserve the license of third-party material.

## Contributor License Agreement

Before a pull request that changes code, tests, or build or runtime configuration
can be merged, each external contributor must explicitly accept the
[bot.Box Contributor License Agreement v1.0](CLA.md) for their contributions to
that pull request. The agreement lets the maintainer reuse and license accepted
contributions on different terms while contributors retain their copyright.

Use the checkbox in the pull request template. A co-author can post the same
statement as a comment from their own account. If an organization holds the
rights and needs to accept through an authorized representative, contact
<jan@dunkel.tech> to record the acceptance before merge. Include the pull request
link, the rights holder's name, and the applicable version of the agreement.

The maintainer verifies acceptance for each external contributor before merge
and records a permalink to the exact version of the agreement accepted. For
private acceptance by email, keep the email as the acceptance record and note
the verification in the pull request.

Disclose any third-party material in the pull request, with its source and
license. The maintainer reviews its terms before merging it.
